# Wool farm

Practical version: 7x5x7 (excluding I/O), 24k/hr, 8 cells (for 2 colors per cell), supports recoloring

'Big' (size is relative!) one: 9x8x7, 50k/hr, 18 cells (1 cell for each color, no recoloring support)

Super Compact: 5x5x5, 15k/hr, 5 cell, supports recoloring.

Ultra Compact: 3x3x4, 3000/hr, 1 cell.
